## ATLAS-PUB-010 — Convert member crate callers to version-change publishing [patch] — todo
- outcome: every member `rust-release.yml` adds `push` (default branch) and a daily `schedule` to its triggers, plus a `publish-pending` job calling `crates-publish-pending.yml` at the ADR 0068 commit. That job alone grants `contents: write` + `id-token: write`. CFDrs passes `apt-packages: libfontconfig1-dev` to the new job and to its release-event gate call, which lacks it today (its `ci.yml` gate call already passes it). The release-event and `workflow_dispatch` jobs keep calling `crates-publish.yml`, gated on those events so push and schedule runs skip them. Each release-event gate call passes the released package, since that event publishes one crate. The gate's 20-minute timeout over a large registry-baseline set is unmeasured, ritk's git-baseline PR gate (`ci.yml`, informational job) took 6.7-10.2 minutes in its five most recent full runs, measured 2026-09-30. The first large push-mode run (ATLAS-PUB-011) records its gate duration here.
- scope: `repos/*/.github/workflows/rust-release.yml`, the filename every crates.io trusted publisher names (ritk included; its `release.yml` is the Python wheel workflow). 14 members already call the shared workflow. 12 carry an inline copy of its body (aequitas, asclepius, CFDrs, eunomia, gaia, helios, hermes, iris, melinoe, mnemosyne, themis, tyche) and convert to the caller in the same change.
- acceptance: per member, the first push-mode run completes: green with `count=0` when nothing is pending, or it publishes and tags the pending set. Record the run ID in the member PR body.
- order: hermes, leto, moirai, melinoe, themis first, since their bumps are pending, then the rest in any order. One PR per member, dispatched one agent per repository.
- priority: correctness; needs: ADR 0068's PR merged (the caller pins its commit).
- links: [ADR 0068](../docs/adr/0068-publish-on-version-change.md), [ATLAS-PUB-003](../backlog.md#atlas-pub-003).
