## ATLAS-PUB-011 — Release the source that outran its published versions [patch] — todo
- outcome: every published crate's default-branch source equals the `.crate` published at its manifest version, or its manifest carries a SemVer-classified bump that ADR 0068's push mode publishes. Separately, a PR that changes a published crate's source without a bump fails.
- basis 2026-09-30 (each member's fetched default vs the tag of its current version, `src/` + manifest): 100 published crates drifted. By member: apollo 20, coeus 14, consus 15, ritk 25, mnemosyne 11, hephaestus 6, athena 3, tyche 2, and 1 each in aequitas, asclepius, eunomia, themis. First failure: the `ritk-image` 0.4.0 release (run 36762108452) could not compile against crates.io `ritk-spatial` 0.2.0. `fix/ritk-version-drift` bumps the ritk-image/ritk-filter closure.
- method per member: `cargo semver-checks --baseline-registry` classifies each drifted crate (breaking → 0.(x+1).0, additive → 0.x.(y+1)). Dependents' requirements move in the same PR, one PR per member in provider-first order (eunomia, aequitas, hermes, leto, moirai, mnemosyne, hephaestus, apollo, athena, coeus, consus, tyche, themis, ritk, asclepius).
- guard: `scripts/atlas-bump-guard.py`, run by `semver-gate.yml`'s `bump-guard` job on member pull requests (it blocks only once the member requires it), fails a crate the PR touches (its `src/**`, `Cargo.toml`, or resolved dependency requirements differ from the merge base) when crates.io already carries its head version and that `.crate` differs, naming it "bump required". Untouched drifted crates and the push-mode run do not fail, so the member bumps proceed. Members get the job by advancing their gate pin ([ATLAS-PUB-013](../backlog.md#atlas-pub-013)).
- priority: correctness; needs: ATLAS-PUB-010 conversion in each member before its bump PR, so that merging the bump publishes.
- acceptance: the scan above re-run reports 0 drifted crates (a `foreign-name` crate sits on a name another account owns and needs its own registry name, ATLAS-PUB-003, before it can be measured); each member's push-mode run lists its published set.
