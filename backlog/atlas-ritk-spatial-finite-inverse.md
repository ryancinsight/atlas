## ATLAS-RITK-SPATIAL-FINITE-INVERSE — `Direction::try_inverse` accepts non-finite arithmetic [correctness] [patch] — todo
- outcome: `Direction::try_inverse` in ritk-spatial returns `None` for a matrix with a non-finite entry and whenever a normalized or eliminated entry of the working matrix or the inverse is non-finite; `CartesianGridGeometry` then reports its existing `NonCartesianGrid::SingularDirection` instead of keeping an invalid index/world pair.
- evidence (ritk origin/main 2af4c7801): `crates/ritk-spatial/src/direction.rs` `try_inverse` rejected only `pivot_value < PIVOT_SINGULARITY_THRESHOLD`; a NaN pivot makes that comparison false, so it returned `Some` of a NaN-filled matrix, and arithmetic that overflowed mid-elimination surfaced as a plausible-looking inverse.
- delivered in ritk `cb6c91a7b` on branch `fix/spatial-finite-inverse` (not yet on the member default): `try_inverse` rejects a non-finite input entry up front, then checks every pivot, every normalized row entry, and every updated entry of the working matrix and of the inverse as it is computed. No grid_geometry.rs change was needed — `CartesianGridGeometry::new` already maps `None` to `NonCartesianGrid::SingularDirection`. The pivot threshold and elimination order are unchanged. Tests: NaN and both infinities at every entry of ranks one, two and three (42 cases) all return `None`; an overflow-during-normalization fixture returns `None`; an exact pivoted shear is accepted; the widest dyadic diagonal that clears the threshold inverts to its exact reciprocal triple; a sub-threshold diagonal stays singular. ritk-spatial: 101 tests pass, strict clippy and fmt clean.
- corrected expectation: this item's original oracle said a `2^1023` to `2^-1023` diagonal stays accepted. It does not, and did not before this change: `2^-1023` is below `PIVOT_SINGULARITY_THRESHOLD`, so the unchanged threshold refuses it as singular. The delivered tests pin the real boundary (accepted at `2^-9`, refused at `2^-1023`) rather than the oracle's unverified claim, so a sub-threshold pivot is reported as singular instead of being forced through the finiteness guard.
