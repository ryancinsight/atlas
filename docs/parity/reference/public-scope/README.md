# Public surface, source views and reusable contracts

This ledger conserves the frozen inventories. It separates the public API
question from source identity, planned provider routing and complete semantics.
It grants no execution, independent numerical, performance or release credit.
The [index](index.json) hashes every consumed artifact; the parity gate checks
every reference identity, exact source-record hash, contract and owner snapshot.

`bindings.json` links each raw declaration to a framework-specific reusable
contract and source detail. `contracts.json` names one proposed accountable
provider where a canonical family supports it. An Atlas evidence/orchestration
or definition-triage owner does not become an implementation assignment. The
framework directories preserve signatures, alias/generated/inheritance evidence,
source receipts, routing reasons and explicit unresolved axes. Matching source
targets or signatures do not establish semantic equivalence.

The first capture retains **38,096 raw candidates** and **147 framework contract
groups**. It identifies 498 unresolved publicness cases, three source-internal
candidates, and nine documented Elastic extension hooks. All remain retained.
The 486 TensorFlow private proposals are unresolved: the current policy page
conflicts with frozen public traversal/golden evidence. Neither a leading
underscore nor an `__internal__` spelling removes a public workflow. Counts of
raw declarations, distinct public spellings, source aliases, semantic variants,
capabilities and executed coverage are different quantities.

The 35,492 initial planned family routes and 2,604 unresolved routes describe
source routing proposals. **Zero implementation owners are verified by this
audit.** The complete API specification still requires each signature's value,
state/effect, dtype/promotion, device, layout/ownership, gradient, staging and
error-domain parameters. Existing `numpy.ndim` and `numpy.shape` source mappings
retain their earlier status; family membership promotes no other API.

## Inspect and reproduce

```sh
python3 scripts/atlas-parity.py report
python3 scripts/atlas-parity-scope.py numpy.shares_memory
python3 scripts/atlas-parity-scope.py jax.grad --framework jax
```

Large record sets use `atlas-column-table-v1`: named columns have explicit JSON
value tables; row cells reference table indexes, and `-1` alone denotes an absent
key. JSON null remains a value. This losslessly deduplicates storage, not public
names or semantics. The inspector expands one selected public spelling, its
raw source detail, proposed contract and separate semantic mapping. Duplicate
original reference payloads are rehydrated from the immutable inventory, with
the complete canonical reference hash checked on every load.

`scripts/parity/capture_public_scope.py` regenerates this representation from
four explicitly supplied source-audit directories. It imports no framework,
executes no native build and accesses no network. Capture receipts bind the
original rich audit bytes and selected provenance/signature/exception inputs.
Source audit replay and mathematical acceptance remain separate obligations;
the presence of a receipt never asserts that a runtime case ran.
